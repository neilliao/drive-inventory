# 峨眉雲端檔案：歸檔規矩（一頁版草稿）

> 給各組各區窗口的說明。目標：講一分鐘就會，照做之後找檔案不用再問人。

## 只有一條規矩

**檔案和資料夾的名字，開頭寫日期加活動名，然後放進當年的年份資料夾。**

格式：`YYYY-MM-DD活動名`

例：`2026-05-12靈隱寺三天法會`

## 各種東西放哪

| 你手上的東西 | 放到哪 |
|---|---|
| 活動照片 | 照片硬碟 → 當年年夾 → 建活動資料夾放進去 |
| 活動錄音 | 錄音硬碟 → 當年年夾 → 同上 |
| 活動影片 | 影音硬碟 → 當年年夾 → 同上 |
| 名冊、流程表、檢討等文件 | 照現行做法進 C 或 D07 對應位置，資料夾名一樣照規矩 |
| 教材、聖歌、範本這類常用資料 | 對應硬碟的編號資料夾（不確定放哪就問文書組） |

同一場活動的照片、錄音、文件**分開放沒關係**——只要名字開頭的日期一樣，系統每個月會自動把它們串成總表上的同一列。

## 為什麼日期要寫對

電腦靠名字開頭的日期認活動。日期寫對，你放的東西就自動出現在「活動總表」上，全道場的人查表就找得到；日期沒寫，東西就變成沒人找得到的孤兒。

## 三個不要

- 不要建「新資料夾」「未整理」「暫存」這種名字的資料夾
- 不要把檔案放在硬碟最外層（一定要進年夾或編號資料夾）
- 不要自己另創一套編號

## 放錯了怎麼辦

改名、重傳自己就能做。要刪掉或搬位置，跟文書組說一聲就好。刪掉的東西會在垃圾桶留 30 天，都救得回來，不用緊張。
