# 道務紀要怎麼落地：借慈濟大藏經的做法（討論稿）

2026-09-15 夜，Neil 說「我們沒有這種東西」（檢討會記錄／會議紀錄裡沒有紀要那一段），要先想清楚怎麼落地，並借慈濟大藏經的經驗讓人容易上手。本稿是查證後的整理，尚未拍板，未動工。

## 慈濟怎麼讓幾千個非專業志工寫得下去（查證自原始資料）

- 活動先存在，報導掛上去：大藏經的報導由「活動訊息系統」帶入，寫的人不填日期地點單位，只填內容。
- 每場活動有專人：2002 年底上人提「文化三合一」，文字、攝影、錄影合成一組（人文真善美志工），每個社區都有，記錄是排好的人做。
- 時效與署名：手冊第一條「活動完畢最好當天或隔天寄傳」；撰文者署真名，理由是「負文責」。
- 有人接、有人看：上傳者→審核者→推薦者→編輯者，每關 email 或簡訊通知，可退回；成品登快報、月刊、大愛台。手冊第十四條：「每天上慈濟網站，看自己作品登出來了嗎？」
- 一頁寫法：首段人事時地物、五 W 一 H、信達雅、全形標點、人物第一次出現寫職稱姓名、「全部都寫等於沒寫」要先拉主軸；照片最多十張，每張圖說加攝影者。
- 使命框架：手冊明講「活動記錄即是歷史」的心態容易厭倦、千篇一律；要從「為時代作見證、為慈濟寫歷史」切入才撐得久。
- 2023 社區網 2.0：手機平板可作業，後臺領任務編輯公開，AI 辨識照片人名。

## 峨眉對得上什麼

| 慈濟 | 峨眉現有 | 缺 |
|---|---|---|
| 活動訊息系統 | 道籍法會表單（日期、地點、主班、助班、操持） | 寫紀要的人仍要重打 |
| 人文真善美專人 | 法會排班文書，本來在錄音拍照 | 沒說「這場誰寫」 |
| 當天傳、署名 | 無 | 節奏、署名欄 |
| 審核鏈、通知 | 文書組長 | 無通知、無退回 |
| 登出來給人看 | 季刊、道峨眉、LINE 小幫手 | 紀要沒出口 |
| 一頁寫法 | 中心手冊道務紀要章 | 未裁成一頁 |
| 使命框架 | 「修行就是寫歷史」（濟公活佛・2009年泰國夜豐頌慈恩壇三天法會） | 已有 |

## 提案（寫的走對話，看的給他）

- 法會結束當晚，道籍 LINE 對值班文書推一句：「今天某場，主班某某。班員幾位？兩三句要點？」回覆即成一筆；日期地點主班由道籍帶入，不重打。照片照原規矩進活動年夾。
- 文書組長收「有一筆待看」，通過或退回。
- 出口：每週一則「本週道務」LINE 推播給幹部，署寫的人的名字；季刊當素材。
- 報導庫那一列由機器寫，人不碰。不會用 LINE 的口述給文書組長代打（文書組＝代打層）。
- 寫法一頁：慈濟十四條裁成峨眉八條，加中心手冊紀要範例。

## 待 Neil 拍板

1. 「這場誰寫」跟法會排班綁在一起？
2. 出口先做哪個：每週 LINE 推播（最快看得到）還是季刊（最慎重）？
3. 這是要動道籍 LINE 的建置，不是改文件；要做先簡報一頁再動工。
