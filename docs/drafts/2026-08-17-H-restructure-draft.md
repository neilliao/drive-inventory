## 待 Neil 拍板的五個問題

1. **H01 與 H02 要不要合併？** 有聲書＝成品出版品，經典講述＝講課錄音系列。分開的理由：消費場景不同（自修聽書 vs 備課取材）；合併的理由：都是「照書講」的音檔。草案先分開。
2. **李講師的錄音帶（33 檔）歸哪？** 人物錄音，可入 H90 當史料，或 H02 當講述系列。
3. **H90 內部按年份建子夾？** 草案建議要——178+ 個活動夾攤平很難翻，`H90/2008/2008-08-23 靈隱寺道德經培訓班/` 這種二層結構跟照片庫的逐年邏輯一致。
4. **無日期散檔 21 檔**（清單在 mapping.csv 篩「無日期」）多為前人／經理級錄音：白水老人講道集、大姑前人講話、宋經理講蔡經理修辦過程、蔡經理慈悲、仙佛慈訓等。建議新開 **H06.人物與訓音史料** 收，或併入 H04。
5. **硬碟改名**：建議「EM：峨眉書院：雲端：8H.錄音」，對齊 1A~7G 命名法。

## 執行方式（拍板後）

1. mover script 讀 mapping.csv，Drive API 批次搬移（檔案 ID 不變、連結不斷）
2. 每批前後快照＋move-log（from→to→經手），可完整回滾
3. 搬完重爬 → 檔案地圖與目錄以新結構定稿
4. 同層 MD5 重複在搬移中順手收斂（H 內部＋H/B 跨碟 32 檔另列 dry-run 清單批准後動）
