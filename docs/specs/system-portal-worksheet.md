# 道務平台｜工作確認單

- 建議角色：平台維護角色＋內容窗口
- 建議驗收：每個入口指向已確認資料；空分類不顯示
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填
