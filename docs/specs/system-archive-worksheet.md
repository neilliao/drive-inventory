# 文獻平台｜工作確認單

狀態：建議草案，現況及排程待確認。

先有內容再做平台；人臉技術選型仍待確認，不自行採用。

## 1. 確認收錄規則

- 交付：欄位表、收錄標準與缺口清單
- 建議角色：典藏編輯角色
- 建議驗收：人、事、理與來源欄位有定義；署名與審核狀態可記錄
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填
