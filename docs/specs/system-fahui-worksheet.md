# 法會文書｜工作確認單

建議草案，非已核定排程。

抄校依原有工法，中心手冊不改寫。主班過目才發放；錄音限奉命者；留存依指示。歸檔、個資權限及私人副本處理，依確認後的規範執行，本頁不代為發放或刪檔。

## 1. 覆核傳承教材

- 交付：三份草稿覆核清單與確認版本
- 建議角色：帶領前賢＋教材整理角色
- 建議驗收：聖佛綸音文書篇、整併大綱、峨眉注意事項逐項覆核；引用能回到來源，中心手冊不另改寫
- 承辦人／覆核人：待填
- 適用場次／日期：待確認
- 前置條件／成果連結／覆核結果：待填

## 2. 確認當場四人分工

- 交付：主抄、副抄、板書、校對分工表
- 建議角色：帶領前賢＋當場文書
- 建議驗收：依既有工法與帶領前賢安排分工；心靜為先，繁體正字，不以未覆核的新流程替代古法
- 承辦人／覆核人：待填
- 適用場次／日期：待確認
- 前置條件／成果連結／覆核結果：待填

## 3. 原稿核校與疑義請示

- 交付：核校紀錄、疑義清單及請示結果
- 建議角色：校對角色＋主班
- 建議驗收：以原稿核校，按授權重聽錄音；未明處列疑請示，不擅改、不濃縮；主班過目後才發放
- 承辦人／覆核人：待填
- 適用場次／日期：待確認
- 前置條件／成果連結／覆核結果：待填

## 4. 確認歸檔位置與繳回

- 交付：產物清冊、確認後的夾位與繳回紀錄
- 建議角色：歸檔窗口＋文書角色
- 建議驗收：逐項核對訓文、錄音、班務檔及檢討紀錄的去處；原頁列班務檔一週內繳回，實施前確認適用規範；個資不散置
- 承辦人／覆核人：待填
- 適用場次／日期：待確認
- 前置條件／成果連結／覆核結果：待填

## 5. 依核定版本整理傳承包

- 交付：確認版本、發放範圍與接手說明
- 建議角色：帶領前賢＋教材整理角色
- 建議驗收：完成草稿覆核與夾位、檔名、成品形式確認後才定稿；中心手冊保持正本引用，不另生工法版本
- 承辦人／覆核人：待填
- 適用場次／日期：待確認
- 前置條件／成果連結／覆核結果：待填

## 6. 安排帶領見習與接棒

- 交付：見習安排、跟班紀錄與接棒檢視
- 建議角色：帶領前賢＋見習文書
- 建議驗收：由前賢帶領，依核定教材練習並回看抄、校、歸的完成情況；是否可承擔由帶領前賢判斷，不只靠教材自行上場
- 承辦人／覆核人：待填
- 適用場次／日期：待確認
