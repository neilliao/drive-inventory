# 知識庫｜工作確認單

狀態：建議草案，現況及排程待確認。

開權限須等個資複核通過；搬移、刪除與權限變更均需另外確認。

## 1. 核對現有盤點

- 交付：正本位置、待搬與待判清單
- 建議角色：檔案窗口
- 建議驗收：每批資料有來源及目標；未決資料獨立列出
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填

## 2. 確認搬移方案

- 交付：經確認的搬移清單與回復方式
- 建議角色：檔案窗口＋執行角色
- 建議驗收：先試搬核對連結及內容，再批准其餘批次
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填

## 3. 個資複核（必要條件）

- 交付：敏感資料清單與處理紀錄
- 建議角色：資料權責窗口
- 建議驗收：個資不散落於一般檔案區；未通過不開權限
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填

## 4. 驗證群組權限

- 交付：授權矩陣與帳號測試紀錄
- 建議角色：權限管理角色
- 建議驗收：授權帳號可取用、未授權帳號不可取用
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填

## 5. 試用與交接

- 交付：目錄、操作說明、巡檢清單
- 建議角色：使用窗口＋接手角色
- 建議驗收：未參與整理的人能依目錄找到指定資料並提出回饋
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填
