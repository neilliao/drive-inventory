峨眉書院・文書

我要做什麼

做事的人從這裡進：一件事，一張卡。

上往下是道找事，下往上是事找道。每張卡四格：怎麼做、交到哪、問誰、為什麼。黃色虛線格＝還沒有答案的地方。這些空格，正是從下往上才看得見的洞，逐格拍板後補上。

法會場上（信）

🙋 我要幫忙法會（掛號、佈置、發本子）
怎麼做現場跟著做就會，零門檻。詳見〈D06 注意事項〉
交到哪名冊、表格當天交文書組長
問誰文書組長
為什麼「每個人都需要機會行功了愿。」（《聖佛綸音・文書篇》#25）
✍️ 我要抄訓、校對
怎麼做四人分工：主抄、副抄、板書、校對；以原稿校對，發放前主班過目（#50）。工法見中心《法會文書參考手冊》
交到哪訓文母本歸文書組，歸檔 202文史
問誰主抄／文書組長；有疑必請示（#49）
為什麼「重點是咱們是否心心相印。」（行德班，冊一原文）
🎙️ 我錄了音、拍了照
怎麼做仙佛臨壇只有文書組奉命者可錄（#55）；檔案不留私人電腦手機（#56）
交到哪錄音 → 204錄音碟；照片 → 206照片碟（活動年夾）
問誰文書組長；要加經手的人，先請示（#57）
為什麼「不要讓它留在自己專屬的電腦。」（#56）
📝 我要寫法會檢討會記錄
怎麼做會後寫好，呈操持確認（D06 修訂草案）
交到哪併入繳回項目，歸 208會議碟（修訂案）
問誰細分夾位、把關人選【待拍板】
為什麼「回去看了才會有憑有據。」（#53）

道務日常（史）

📋 我要寫會議記錄（策畫會、聯絡圈）
怎麼做執筆是誰、用什麼格式、多久交【待拍板：工作清單第一條四格】
交到哪208會議碟（10 靈隱／20 峨眉／30 經理附件）
問誰把關人未指定【待拍板】
為什麼「未來佛也得要記。」（#53）
🗂️ 我辦完活動，檔案要歸位
怎麼做檔名以日期開頭「YYYY-MM-DD活動名」，放進自己單位碟的 90 年夾
交到哪各組桌／區桌碟的活動年夾
問誰歸檔窗口（組長、副組長、區文書）
為什麼「註明出處、地點、時間。」（#43）
🔎 我要找一份檔案
怎麼做先查全組織檔案地圖與目錄總表；三把鑰匙：人＝編號、事＝日期、理＝詞條
入口在哪一般人找得到的前門還沒開【道務平台開門後解決】
問誰歸檔窗口
為什麼「有憑有據。」（#53）
📚 我要借書、還書
怎麼做借閱流程懸空：系統有借閱模組但幾乎沒在用，實務疑仍在試算表【待與文書組確認】
交到哪借閱、歸還紀錄（峨眉書籍資料庫）
問誰文書組
為什麼圖書這條線在藍圖上還沒有位子【待拍板】
📣 我要發通知給大家
怎麼做一次發送、多路到位（檔案權限＋LINE＋信箱同一套名單）
操作路徑發布口設計好了，工具還沒接上線【待施工】
問誰發布的把關人未指定【待拍板】
為什麼「及時給眾生，不要斷了熱度。」（#44）
🖋️ 我想投稿、寫採訪心得
怎麼做投給道峨眉季刊；訪談與心得照日期歸年夾入庫（採集迴路）
交到哪701道峨眉碟；刊出後成為當代史料
問誰季刊編輯
為什麼「從白話訓裡面去擷取重點。」（#41）

人的路（徑）

🌱 我想多學一點
怎麼做從幫忙開始，帶的人會開口邀你。路徑見〈文書育才路徑〉
教材傳承包四件：《聖佛綸音・文書篇》選輯、中心手冊、注意事項、育才路徑
問誰帶你的人／文書組長
為什麼「一個人念，一個人抄，你們才有體會。」（#26）
🤝 我想帶一個新人
怎麼做三個動作：讓他看見、邀他試一步、陪他過第一次（育才路徑第五階）
名單接棒名單、每年檢視的節奏【待拍板】
問誰文書組長
為什麼「交棒要及早。」（#63）

從下往上，看見了什麼

把每件事的四格逐一填過一遍，黃格子自己浮出來了。歸納成六個從上往下沒想到（或還沒想完）的洞：

  1. 責任到了系統，還沒到人。印是碟級的責任名牌，但「這件事卡住了問哪一位」多半沒有名字：工作清單的「誰動手、誰把關」欄整排待填。下往上看，最缺的不是規矩，是活人的窗口。（會議記錄、發通知、檢討會三張卡的黃格）
  2. 圖書是條孤兒線。發放、借閱兩套帳都在，但活、脈、彰三顆印沒有一顆管實體書；借閱實務疑似還在試算表上跑。要嘛給它一個家，要嘛正式決定維持現狀。（借書卡整張偏黃）
  3. 找檔案的路蓋好了，門牌還沒掛。索引、鑰匙、目錄都在，但一般人不知道從哪裡進。這正是道務平台該開的門，開門前這條路只有內行人走得到。
  4. 發通知有設計、沒有操作。一魚多吃的名單制度到位，但「一位組長今天要發一則通知」的實際按鈕還不存在。
  5. 「為什麼」的窗只開了一半。法會場每件事都有訓文可釘；道務日常有幾件（借書、找檔案）還接不到一句訓。意義的線越往日常越細，這是選輯下一輪可以留意的方向。
  6. 一般道親還沒有自己的卡。這一頁的「我」多半是文書與窗口；「我想看活動照片」「我想查某年的紀念刊」這種道親視角的事，得等前門開了才有答案。
