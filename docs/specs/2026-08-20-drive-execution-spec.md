## 2. 已知技術限制（寫死，避免踩坑）

1. **跨共用硬碟不能整夾搬**：Drive API 不支援資料夾跨碟移動。做法＝目的碟先建骨架、逐檔搬移（106錄音 已驗證此模式）。
2. **API 能否開共用硬碟未實測**：`drives.create` 受網域設定影響。B0-4 先實測；不行則產出 Admin console 手動清單（14 顆，約半小時一次性）。
3. **共用硬碟權限整顆給**：鎖不了單一資料夾——個資出清（第 3 步）因此是掛權限（第 4 步）的硬前置。
4. **批次寫入可能被攔**：8/17 曾發生自動化分類器攔搬移（成功率降 57.5%）。搬移腳本一律本機終端跑，不在對話環境跑。
