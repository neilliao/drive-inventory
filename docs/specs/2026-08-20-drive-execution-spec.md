## 2. 已知技術限制（2026-08-20 對官方文件查證後修訂；B0-5 實測後回填定稿）

1. **跨共用硬碟不能整夾搬**：資料夾不能跨碟移動，做法＝目的碟建骨架、逐檔搬（105錄音 已驗證）。且**檔案跨碟移動需 Manager 權限**——內容管理員只能碟內搬。搬移腳本一律用管理員帳號跑。
2. **API 能否開共用硬碟未實測**：`drives.create` 受網域設定影響。B0-4 實測；不行則 Admin console 手動清單。
3. **共用硬碟權限模型（8/20 二次實測修訂）**：主權限整顆給；資料夾層可授權至**內容管理員**（新增/編輯/移動/刪除/分享——Neil 於 4D/D01 共用選單親測，**推翻**先前「上限協作者」認知）；但資料夾層**無「管理員」選項**（管成員、發鑰匙、永久刪除仍碟級專屬）。「一單位一顆碟」依據修正為：①組長/區長任管理員僅碟級可授 ②側欄分疊命名整體性 ③權限對帳一張矩陣 ④圖書館容量與 103/110 專屬層。資料夾級內容管理員轉列正面工具（碟內委託授權）。被授權者實際搬刪行為待 B0-5 以第二帳號功能性驗證。另「限制存取資料夾」（UI：限制存取「資料夾名」）**已證實存在於 emsy.tw**（2026-08-20 Neil 於 4D/D01 右鍵親測，未實際套用）；UI 文字並證實**管理員永遠穿透**（organizer 不受鎖限制）。本設計仍不依賴它（103/110 獨立成碟），列為未來加分工具。
4. **容量上限 50 萬項目／顆**（含垃圾桶與捷徑；舊記錄 40 萬有誤）。圖書館現有 376,484 筆＝單顆的 75%，合併不可行；另每人每日上傳上限 750GB，907攝影與 904-906 大批搬移分日跑。
5. **批次寫入可能被攔**：8/17 分類器攔搬移前例。搬移腳本本機終端跑。
6. **文件≠實況**：功能受 Workspace 版本與管理員設定影響。B0-5 於測試碟逐條實測後，本節以實測結果為準回填。
