# 道籍系統｜工作確認單

狀態：建議草案，現況及排程待確認。

不得直接修改真實名冊或權限；須另行確認執行範圍。

## 1. 確認正本與維護窗口

- 交付：正本欄位與維護責任表
- 建議角色：資料窗口＋系統維護角色
- 建議驗收：同一人不重複建檔；異動可追溯
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填

## 2. 測試活動與陪伴紀錄

- 交付：指定活動的端到端測試紀錄
- 建議角色：業務窗口＋系統維護角色
- 建議驗收：一筆活動紀錄能回連同一人；敏感內容依授權隔離
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填

## 3. 驗證職務權限與自助查詢

- 交付：授權矩陣、查詢測試與交接文件
- 建議角色：各單位窗口＋權限管理角色
- 建議驗收：授權者可用、未授權者不可讀；接手者依文件完成例行作業
- 現況證據：待填
- 試行範圍：待填
- 承辦人／複核人：待填
- 前置條件：待確認
- 日期：待確認
- 成果連結／驗收結果／修正事項：待填
